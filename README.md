Developed a native Android (Java/XML) educational application utilizing MVC architecture for interactive English vocabulary practice.

Optimized data management by parsing Android String Resources (strings.xml) at runtime for lightweight data retrieval without external databases.

Engineered a custom randomization algorithm with duplicate-check mechanisms to dynamically generate unique multiple-choice options.

Managed Activity lifecycles and state passing via Explicit Intents for UI reusability, and implemented asynchronous UI feedback using Handlers.

Tech Stack: Java, Android XML, Android Studio, MVC Architecture
